# 👑 GPKING Messenger

**GPKING** is a modern messaging platform built to connect people across devices.

Our goal is to create a convenient, accessible, and privacy-conscious messenger with a shared account system for web and mobile clients.

## 🚀 Vision

GPKING aims to bring messaging, media sharing, and real-time communication together in one place.

## ✨ Planned Features

- 💬 Real-time text messaging
- 👤 User accounts and authentication
- 🟢 Online status
- 📷 Photo and file sharing
- 🎙️ Voice messages
- 📞 Audio calls
- 🎥 Video calls
- 📱 Responsive web interface
- 🤖 Android application
- 🔄 Shared accounts across devices
- 🔐 Security and privacy-focused design

## 🛠️ Planned Technology Stack

| Technology | Purpose |
|---|---|
| HTML, CSS, JavaScript | Web interface |
| GitHub Pages | Static website hosting |
| Supabase | Authentication, database, storage, and realtime features |
| WebRTC | Audio and video communication |
| Capacitor | Potential Android application packaging |

The technology stack may evolve as development progresses.

## 🔒 Security and Privacy

Security and privacy are important development goals.

GPKING will aim to:
- Protect user accounts and data.
- Apply appropriate database access controls.
- Avoid unnecessary collection of personal information.
- Keep secret credentials out of public repositories.
- Evaluate end-to-end encryption before making claims about message confidentiality.

**Note:** GPKING is under active development. Features and security protections are not yet complete.
